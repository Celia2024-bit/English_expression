have long done sth vs have done sth for a long time

书面 / 辨析

have long + 过去分词（如 long wanted / known / believed）＝早就……了，比较正式、书面，位置在动词前；have done … for a long time 则是普通、口语的说法。have long since done 强调“早就已经……”。

快速定位：早就……了（书面 vs 口语）

I have long wanted to visit Japan.
我早就想去日本了。（书面）
I have wanted to visit Japan for a long time.
我想去日本很久了。（普通说法）
Scientists have long known that sleep affects memory.
科学家早就知道睡眠会影响记忆。
He has long since moved away.
他早就搬走了。
