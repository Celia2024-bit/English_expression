run the show / run sb's life / let sth run your life

口语 / 辨析

都有“掌管”的意思，但管的对象不同：run the show＝在某个场合或团队里说了算、负责全局；run sb’s life＝干涉、支配某个人的个人生活，多含贬义；let sth run your life＝让情绪、工作等事物支配自己的生活。

快速定位：辨析：掌管全局 vs 支配生活

Who's running the show here?
（掌管全局）这里谁说了算？
The manager is away, so Sarah is running the show this week.
（掌管全局）经理不在，这周由 Sarah 负责全局。
Stop trying to run my life!
（干涉别人的生活）别再想支配我的生活了！
I'm old enough to run my own life.
（自己做主）我已经大到可以自己做主了。
Don't let fear run your life.
（让事物支配生活）别让恐惧支配你的生活。
I don't want my job to run my life.
（让事物支配生活）我不想让工作支配我的生活。
